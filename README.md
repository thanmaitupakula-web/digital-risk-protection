# Digital Risk Protection Prototype

A working prototype for the Digital Risk Protection challenge, focused on Social & App Monitoring.

## Features

- Brand profile setup with official assets and verified application list
- Social monitoring dashboard for impersonating profiles and scam pages
- App monitoring dashboard for suspicious apps and developer mismatches
- Look-alike name detection examples using normalized name similarity
- Architecture section showing data sources, detection logic, and action flow
- Demo slides summarizing the proposed approach

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Build

```bash
npm run build
```
